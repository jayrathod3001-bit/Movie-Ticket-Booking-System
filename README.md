# Movie Ticket Booking System

A modern web-based Movie Ticket Booking System developed to provide a secure, scalable, and user-friendly platform for online movie reservations. The application allows users to browse movies, view show timings, select seats, and book tickets efficiently through an interactive and responsive interface.

---

## 🚀 Features

- User Authentication System
- Movie Listings & Details
- Show Timing Management
- Online Ticket Booking
- Seat Selection System
- Booking Confirmation
- Admin Dashboard
- CRUD Operations
- Database Integration
- Responsive User Interface

## ⚙️ Installation

```bash
git clone https://github.com/jayrathod3001-bit/movie-ticket-booking-system.git
cd movie-ticket-booking-system
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
